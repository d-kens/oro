# Oro

Oro is a place to learn cloud and DevOps. It teaches the skills cloud engineers use every day, one step at a time, with clear notes and labs that run on your own computer.

Live at <https://oro.co.ke>. To run the site on your own computer, see [CONTRIBUTING.md](CONTRIBUTING.md).

## What's on the site

- **Skills:** each skill is a set of topics taught in order. Every topic has a lesson, hands-on tasks and a short quiz, and every skill ends with projects. The skills written so far are What is DevOps, Linux, shell scripting, networking and cloud computing.
- **Roadmaps:** a roadmap puts skills in the order to learn them for a role. The first one is for DevOps engineers, and more are planned.
- **Projects:** larger pieces of work that bring a skill's lessons together, such as setting up a new machine or writing a deploy script.
- **Community:** a WhatsApp group where learners ask questions and share their progress.

Labs and projects run locally, so you don't need a cloud account or a credit card.

## Who it's for

Beginners new to tech, people moving into cloud work from another job, and working engineers who want to fill gaps such as Linux, networking and how the cloud works.
